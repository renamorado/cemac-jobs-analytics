# Tax classification check against INS ECOFIN 2019

Checked 29 September 2026. **The raw tax data use NACAM Rev.1 branch numbering.** This is the established project interpretation for `CODEBRANCHE` in the original workbook and `nacam` in BDF, covering 2015–2022. The official [ECOFIN 2019 report](https://ins-cameroun.cm/wp-content/uploads/2025/06/Rapport-ECOFIN-2019-Final.pdf), published May 2021, and the comparisons below support this decision. The report directly covers 2015–2019; later-year continuity is supported by the existing code-history and company-name checks.

## Evidence

- Page 79 explicitly describes 43 DSF branches compatible with NACAM Rev.1 and NAEMA Rev.1 (2011).
- Annex A2, printed/PDF pages 80–81, reports 37 populated branch codes for 2015–2019. Their code set equals our 37 observed codes. Its code labels agree with the Rev.1 interpretation, including 030 water/sanitation/waste, 031 construction and 032 trade/vehicle repair.
- Every branch count matches the source BDF row count in 2016 and 2017: 37 of 37 in each year. In 2015, 34 match; in 2018, 35 match; in 2019, 19 match. This close pattern supports a common ECOFIN classification and related extracts, without proving identical firm membership.
- The report calls its counts enterprises. Our raw rows are not always distinct firms. The script reports source rows, distinct firms within each branch/year, and cleaned firms separately. Raw duplicate/conflicting firm-years prevent treating row-count equality as firm-level identity.
- Report totals are 1,258, 1,256, 1,265, 1,221 and 1,185. Our source row totals are 1,255, 1,256, 1,265, 1,220 and 1,133. The larger 2019 difference remains unexplained; neither the classification nor the cleaning rules were changed to force agreement.

## Interpretation

Use NACAM Rev.1 for tax classification. The older labels were based on a recorded revision assumption, whereas this report identifies the ECOFIN classification explicitly and reproduces two complete annual count profiles from our source. Code 030 is water/sanitation/waste, construction is 031, and trade/vehicle repair is 032. The earlier legacy labels and their 27-unresolved mapping result are superseded.

The report directly covers 2015–2019; applying the same revision in 2020–2022 still draws on the existing code-history and company-name audit. It does not certify each firm's activity, resolve partial ISIC boundaries, or establish identical samples. Keep the existing revision flag and audit trail; no production slides, regressions, classifications or data were overwritten for this comparison.

## Reproduction

Run `do "code/elasticity_cameroun/25_cmr_tax_ecofin2019_comparison.do"` from the project root. This reads the existing BDF source and cleaned files, and `docs/reference/cmr_ecofin2019_branch_counts.csv`. Outputs are two aggregate CSVs in `output/checks/tax_ecofin2019/`, an esttab fragment in `output/tables/cmr_tax_ecofin2019_comparison.tex`, and the step log.

The reference CSV was extracted with pdfplumber from the PDF's embedded text/table cells. The PDF table extractor splits the final 2019 column into two cells; these were concatenated before conversion to integers. Both table pages were rendered and inspected, all 37 codes and 185 branch-year values retained, and each annual sum checked against the printed totals. No OCR was needed. The downloaded PDF and text are in `docs/reference/tax_isic4/Rapport-ECOFIN-2019-Final.pdf` and `.txt`.
